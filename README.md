# Podosul Marketing Engine

## Rodar localmente
1. Instale Node.js LTS.
2. Abra o terminal na pasta do projeto.
3. Rode `npm install`.
4. Rode `npm run dev`.

## Rodar online na Vercel
1. Faça upload do projeto para um repositório GitHub.
2. Importe o repositório na Vercel.
3. Use a configuração padrão de Vite.
4. Adicione a variável de ambiente `VITE_GEMINI_API_KEY` se quiser IA real.

## Build
- comando: `npm run build`
- saída: `dist`
